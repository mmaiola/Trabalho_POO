Oficina Garagem

Sistema de gerenciamento de clientes, veículos, serviços e ordens de serviço.

1. Tema escolhido

Gestão de uma oficina mecânica, com foco no registro de clientes, veículos atendidos, serviços oferecidos e acompanhamento das ordens de serviço.

2. Descrição do problema

Oficinas precisam manter organizadas as informações de seus clientes e veículos, registrar os serviços solicitados e acompanhar o andamento dos atendimentos. Quando esses dados são controlados manualmente, podem ocorrer perda de informações, dificuldade de consulta e falta de histórico dos serviços.

3. Objetivo do sistema

O Oficina Garagem tem como objetivo oferecer uma aplicação simples, executada pelo terminal, para cadastrar e consultar clientes, veículos e serviços, além de abrir ordens de serviço e atualizar seu status. As informações são armazenadas em arquivos locais, permanecendo disponíveis após o encerramento do programa.

4. Requisitos funcionais

CódigoDescrição
RF01O sistema deve permitir cadastrar clientes, armazenando nome e telefone.
RF02O sistema deve listar os clientes cadastrados.
RF03O sistema deve permitir cadastrar veículos vinculados a um cliente existente.
RF04O sistema deve listar os veículos cadastrados e seus respectivos proprietários por identificador.
RF05O sistema deve permitir cadastrar serviços com descrição e valor.
RF06O sistema deve permitir abrir uma ordem de serviço relacionando cliente, veículo e serviço.
RF07O sistema deve listar as ordens de serviço registradas.
RF08O sistema deve permitir atualizar o status de uma ordem de serviço.
RF09O sistema deve salvar e recuperar os registros em arquivos locais.

Dados: responsabilidade de ler e gravar os registros nos arquivos CSV.
Main: apresenta o menu e coordena as operações do sistema.

Relacionamentos: um cliente pode possuir vários veículos; cada ordem de serviço referencia um cliente, um veículo e um serviço do catálogo. A classe Dados centraliza a persistência em arquivos.

6. Tecnologias e execução

Java 17 ou superior, terminal e arquivos CSV locais. Para executar, compile os arquivos Java e inicie a classe oficina.Main, conforme os comandos disponíveis no README do repositório.
